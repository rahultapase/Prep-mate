## 📖 About

PrepMate runs a full mock interview on your own machine. It reads your resume and the job description, asks tailored questions out loud, records your spoken answers, and then scores each answer with written feedback. The AI model (Gemma 4) runs locally through Ollama, and all data is stored in a local SQLite file.

## ✨ Features

- 🤖 **AI interviewer** - Questions generated by Gemma 4 from your resume, target role, company and job description
- 📄 **PDF resume upload** - Text is extracted in the browser and can be edited before the interview; pasting text also works
- 🎙️ **Voice answers** - Questions are read aloud and answers are captured with speech-to-text
- 📚 **Interview types** - Technical, HR and Managerial
- ⚡ **Scored feedback** - Per-question communication and technical/behavioral scores, comments, an overall score and improvement tips
- 📊 **Dashboard** - Interview history with search, filters, sorting, detailed feedback view and delete
- 📈 **Adaptive difficulty** - Questions get harder after 5 completed sessions of the same type
- 🔒 **Private by default** - The server only listens on `127.0.0.1`, and resumes, answers and feedback stay on your machine

## 🚀 Getting Started

### Prerequisites

- **Node.js 22** or newer - [Download](https://nodejs.org/)
- **Ollama** - [Download](https://ollama.com/download)
- **Google Chrome or Microsoft Edge** - Needed for speech-to-text. Chrome's speech recognition uses Google's online service, so an internet connection is required while answering.
- A webcam and microphone

### 1. Get the Gemma 4 model

```bash
ollama pull gemma4:e2b
```

`gemma4:e2b` is about 4.6 GB and runs on most laptops with 16 GB RAM. If you have more memory or a stronger GPU, `gemma4:e4b` gives better questions and feedback (set `OLLAMA_MODEL` below).

Make sure Ollama is running. The desktop app starts it automatically, or run:

```bash
ollama serve
```

### 2. Install

```bash
git clone https://github.com/rahultapase/Prep-mate.git
cd Prep-mate
npm install
```

### 3. Configure

Copy the example environment file:

```bash
# macOS / Linux
cp .env.example .env

# Windows (PowerShell)
Copy-Item .env.example .env
```

| Variable | Default | Description |
|---|---|---|
| `PORT` | `3001` | API server port |
| `HOST` | `127.0.0.1` | Address the API server listens on |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Ollama server URL |
| `OLLAMA_MODEL` | `gemma4:e2b` | Model used for questions and feedback |
| `OLLAMA_NUM_CTX` | `16384` | Context window size sent to Ollama |
| `OLLAMA_TIMEOUT_MS` | `180000` | Maximum wait for one AI response |
| `DEMO_EMAIL` | `rahul@prepmate.local` | Login email of the demo account |
| `DEMO_PASSWORD` | `demo1234` | Login password of the demo account |
| `DEMO_NAME` | `Rahul` | Display name of the demo account |

The demo account is created the first time the server starts.

### 4. Run

```bash
npm run dev:full
```

This starts the API server on `http://127.0.0.1:3001` and the app on **http://localhost:5173**. Open the app in Chrome and log in with the demo account:

- Email: `rahul@prepmate.local`
- Password: `demo1234`

## 🎯 Usage

1. **Log in** with the demo account.
2. **Set up your profile** (optional) from Home or Dashboard.
3. **Start an interview** and fill in your name, role, company, experience and interview type.
4. **Add your resume** by uploading a PDF or pasting the text, and optionally paste the job description.
5. **System check**: allow camera and microphone access. The check also confirms the AI model is ready.
6. **Interview**: listen to each question, click **Start Answering**, speak, then move to the next question. A session lasts 20 minutes, with 2 minutes per answer.
7. **End the session** to get feedback, then rate the experience.
8. **Review** past interviews and feedback on the Dashboard.

> 💡 Generation runs on your hardware. Questions usually take 20-60 seconds and feedback 10-30 seconds with `gemma4:e2b`, depending on your machine.

## 🔌 API

All endpoints except login and health need a session cookie.

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/login` | Log in and start a session |
| POST | `/api/auth/logout` | End the session |
| GET | `/api/auth/me` | Current user, or `null` |
| GET, PUT | `/api/profile` | Read or save the profile |
| GET | `/api/interviews` | Interview history, newest first |
| GET | `/api/interviews/count?type=` | Completed sessions of one type |
| POST | `/api/interviews` | Save an interview with its feedback |
| DELETE | `/api/interviews/:id` | Delete one of your interviews |
| POST | `/api/ratings` | Save an experience rating |
| POST | `/api/ai/generate` | Send a prompt to Gemma (`{ prompt, json?, schema? }`) |
| GET | `/api/health` | Server status and Ollama/model availability |

## 🧰 Troubleshooting

| Problem | Fix |
|---|---|
| System check says "Ollama is not running" | Start Ollama (`ollama serve` or the desktop app) and click **Retry** |
| System check says "Model missing" | Run `ollama pull gemma4:e2b`, or set `OLLAMA_MODEL` to a model you have |
| "Speech recognition is not supported" | Use Google Chrome or Microsoft Edge |
| Answers are not transcribed | Check the microphone permission and your internet connection |
| AI responses time out | Use a smaller model, or raise `OLLAMA_TIMEOUT_MS` |
| PDF upload says there is no selectable text | The PDF is a scan; paste the resume text instead |
| Start over with an empty database | Stop the server and delete the `data/` folder |

## 🔒 Security Notes

PrepMate is built to run on a single machine:

- **Bound to localhost:** the API listens on `127.0.0.1` only.
- **Passwords:** stored as bcrypt hashes.
- **Sessions:** use httpOnly cookies, and only a hash of each session token is stored.
- **Not production-ready:** it isn't hardened for a public network. Don't change `HOST` to expose it without adding HTTPS, rate limiting and proper user management.
